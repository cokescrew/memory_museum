# 추억 박물관 — 처음부터 실행하는 방법

## 1. 준비
- Node.js 18 이상 (권장 20 또는 22)
- MySQL Server 8.x 및 MySQL Workbench

## 2. 환경설정
1. 이 폴더의 `.env.example`을 복사해서 이름을 `.env`로 변경합니다.
2. `DB_PASSWORD`를 **본인 MySQL 비밀번호**로 수정합니다.
3. `SESSION_SECRET`에 충분히 긴 임의 문자열을 넣습니다.
4. `ADMIN_PASSWORD`는 로컬 테스트용으로 1234를 사용할 수 있으나 공개 배포 전에 반드시 변경합니다.

## 3. 최초 DB 생성 (둘 중 하나)
**방법 A: 자동 생성(권장)**
```powershell
npm install
npm run db:init
```
`db:init`은 `sql/schema.sql`을 실행하며, 기존 테이블은 `IF NOT EXISTS`로 보존합니다. `추억 찾기` 테이블도 포함되어 있습니다.

**방법 B: MySQL Workbench**
Workbench에서 `sql/schema.sql` 전체를 열고 실행합니다. 이미 기존 DB를 운영 중이고 `추억 찾기` 테이블만 추가할 때는 `sql/add_find_board.sql`만 실행합니다. **둘 다 실행할 필요는 없습니다.**

## 4. 웹사이트 시작
```powershell
npm start
```
브라우저에서 http://localhost:3000 으로 접속합니다.

## 5. 주요 주소
- `/` : 메인 화면
- `/archive` : 추억 저장소
- `/citizen` : 모두의 추억 (익명 게시판)
- `/find` : 추억 찾기 (익명 물건 찾기 게시판)
- `/about` : 제작 의도
- 페이지 하단 `©` 버튼 : 관리자 인증 모달
- `/admin/dashboard` : 관리자 인증 후 관리 화면

## 6. 동작 확인
1. 메인 페이지에서 추억 저장소/모두의 추억 이동 확인
2. `/find`에서 글 작성 후 댓글 등록 확인
3. 푸터의 `©`를 눌러 관리자 비밀번호로 인증
4. 관리자 모드에서 게시글 삭제 및 복구 확인
5. 메인 이외 화면의 좌우 광고 배너 확인 (넓은 화면에서 표시)

## 주의
- `node_modules`와 실제 `.env`는 ZIP에 포함하지 않았습니다. `npm install`이 필요합니다.
- 좌우 배너는 **시연용 광고 자리**이며 광고 플랫폼과 연결되어 있지 않습니다.
- 실제 운영 배포 전 CSRF 토큰, 세션 저장소, 관리자 로그인 시도 제한, 보안 헤더, HTTPS 등을 보강하세요.
- 기존 소스 기반 통합본이며, 이 환경에서는 실제 MySQL 서버를 띄운 종단간 테스트를 수행하지 못했습니다.
